  Hypomnema installs and signs in. Use when the owner asks about their mail, calendar or files: what arrived today,

  sending a reply, creating an event, uploading a file. Not for a Google account Hypomnema was not given.

# Google Workspace

This stub loads the guide that ships with the `hypomnema` binary on this machine, so the guide matches the `gws`
that binary set up.

1. Run `hypomnema skills get google-workspace` once in the session and follow the guide it prints.
2. When the guide names a reference for the work at hand, load only that one:
   `hypomnema skills get google-workspace --reference <name>`.

When `gws` says you were given no Google account, tell the owner: an account is connected in Settings, Integrations,
and switched on there for chats.
