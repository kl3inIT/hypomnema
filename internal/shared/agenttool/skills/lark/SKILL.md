  calendars, tasks) with the lark-cli command, which Hypomnema installs and signs in. Use when the owner asks about
  something in Lark: reading or writing a document or a sheet, a Base table, a wiki page, a file, sending a message
  as the bot, a calendar the app can see. Not for a person's own mail, calendar or drive: the command acts as the
  app, not as the owner.

# Lark

This stub loads the guide that ships with the `hypomnema` binary on this machine, so the guide matches the
`lark-cli` that binary set up.

1. Run `hypomnema skills get lark` once in the session and follow the guide it prints.
2. The guide names `lark-cli`'s own guide for each kind of work; read only the one the work needs, with
   `lark-cli skills read <name>`.

When `lark-cli` says you were given no Lark account, tell the owner: the app is connected in Settings, Integrations,
and switched on there for chats.
