---
name: android-device
description: >-
  Drives the Android phone a Hypomnema node holds (an emulator with Google Play) with the device_* tools: looks at
  the screen with numbered boxes, taps, swipes, types in any language, presses keys, opens apps and reads the log.
  Use to test or use an Android app on that phone, such as the owner's own apps. Not for signing in to accounts or
  paying, which the owner does.
---

# Android phone

This stub loads the guide that ships with the `hypomnema` binary on this machine, so the guide matches the phone
tools that binary offers.

1. Run `hypomnema skills get android-device` once in the session and follow the guide it prints.
