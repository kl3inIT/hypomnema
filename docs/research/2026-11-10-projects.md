a project, and why it sits in Settings and not in the app's sidebar. Clones are in `.tmp/`. A line marked
"(agent)" was read by a sub-agent and not opened again; the rest was opened in the code.

## What they agree on

- The word is **project** in seven of eight. "Repository" is what a project points at, never the name of the thing
  the user manages.
- A project is what work is **grouped by**, and it is seen where the work is: the sidebar, or a filter or picker
  over the work. No reference keeps it only in Settings.
- Settings holds a project's **own settings**, a page a project (Orca, t3code): name, icon, the base branch,
  where its worktrees go, a setup script, the default model.
- Where work runs on more than one machine, a project is one thing and each machine has its **own copy** of it:
  Orca's "Available Hosts" ("Hosts where this project is set up."), t3code's "Checkouts" and "Add to another
  machine". The copy is made by cloning from the project's URL.
- A project is added from a local folder, from a clone URL, or new. t3code also takes `owner/repo` for a host
  whose integration is set up. None lists the user's repositories from the host except OpenHands (agent).
- Work without a project is allowed where the product is not only for code: t3code ("start without one"),
  OpenClaw ("New workspace", the default).

## Where they differ

- Whether the sidebar is grouped by project (Orca, Omnigent, Hermes, Coder) or is an inbox by state with a project
  filter (t3code).
- Whether a project must be bound to a repository (Orca, OpenClaw, Hermes) or is a container for chats with its
  instructions and memory (Coder, Omnara).

## For Hypomnema

Inference, not read in any reference:

- A registered repository is already a project without its name: a name, a URL, a base branch. What it lacks is
  what makes a project worth having: the work grouped under it, and settings of its own.
- A project maps onto what exists: the Runs on its repository, the chats that started them, and on each node the
  mirror clone the node already keeps (a "checkout" in t3code's word).
- Runs and chats without a repository are already allowed (2026-11-10 vision change), as in t3code and OpenClaw.
