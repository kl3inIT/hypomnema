On `main` at `cd76d96e`, the node's worker environment inherited host temp settings and repository setup
did not replace them. The private Dispatch temp arrived on the original PR, not on that base. Even with
`TMPDIR`, Go's `cmd/go/internal/work/action.go:298` passes `GOTMPDIR` to `os.MkdirTemp`; a nonempty Go setting
overrides the ordinary temp fallback. Explicitly set both for setup and the worker. No hard-coded `/tmp`
creator for `refs.*`, `pg-tsk*` or `pgdata` was found in the node or its setup scripts. The names alone do not
identify which worker or test created those directories. The reported server was not inspected.
