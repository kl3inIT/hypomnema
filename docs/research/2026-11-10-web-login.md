# A built-in account for the web

Date: 2026-11-10. The owner wants the web to sign in with a username and a password instead of a pasted owner token,
and to stay signed in for 30 to 90 days. Read by a Sonnet scout in the clones under `.tmp/`: Omnigent at cf1021e,
9router at 1fe586b, 9router-go at 64c156d, new-api at bd6bb53, CLIProxyAPI at c5251b5, Coder at b798061, nezha at
3e7d9ba; Onyx and LiteLLM only in passing. Infisical, OpenClaw and Omnara have no local password login for a web UI
(OpenClaw's control UI takes a gateway token, which is what Hypomnema copied on 2026-11-09).

## 1. What each does

| | First account | Password kept as | The browser holds | Lifetime, and how a session ends | Against a forged request | Against guessing | Tokens beside it |
|---|---|---|---|---|---|---|---|
| Omnigent (`server/accounts_auth.py`, `auth.py`) | None shipped: an environment variable or `--admin-password`, a prompt, or a first-run page that closes once an account has a password; at least 8 characters | argon2id, the library's defaults | A signed token (JWT) in an HttpOnly cookie, `SameSite=Lax`, `Path=/`, `Secure` and the `__Host-` prefix on HTTPS | 8 h, fixed; a password change raises a generation number every token carries, which ends the others | `SameSite=Lax`; an `Origin` check on WebSockets | none | The cookie first, then `Authorization: Bearer`, in one function |
| 9router, 9router-go (`internal/auth/session.go`) | A shipped password, `123456`, or `INITIAL_PASSWORD`; a remote login with the shipped one is refused | bcrypt, cost 10 | A JWT in an HttpOnly cookie, `SameSite=Lax` | 24 h, fixed | `SameSite=Lax` | Per address: 5 failures, then a lock of 30 s, 2 min, 10 min, 30 min, answered 429 with `Retry-After` | A header for the local CLI |
| new-api (`service/auth_session.go`) | A shipped `root` / `123456` | bcrypt, cost 10 | An HttpOnly, `SameSite=Strict` cookie that renews a 15-minute token | 30 days from the login, a row in the database, the secret kept as an HMAC, rotated on use | `SameSite=Strict` and an `Origin` check | 20 requests in 20 min | yes |
| Coder (`coderd/httpmw/apikey.go`, `userauth.go`) | None shipped: a first-run form, or `coder server create-admin-user`; `coder reset-password` | PBKDF2-SHA256, 65535 rounds (for FIPS) | An HttpOnly cookie that is a key with a row in the database | 24 h, extended on use; the secret kept as its SHA-256; a new login removes the old key | A header token, skipped for a request with a token and no cookie | 60 a minute | The cookie, a header and API tokens through one middleware |
| CLIProxyAPI | A management key from the environment or the config | bcrypt | Nothing: the key on every request | none | not applicable | 5 failures, then 30 min | not applicable |
| nezha | not found | bcrypt | A JWT cookie, `SameSite=Lax`, readable by the page | 1 h | `SameSite=Lax` | not found | cookie and header |

Onyx keeps a session 7 days; LiteLLM takes `UI_USERNAME` and `UI_PASSWORD` from the environment.

## 2. Read for Hypomnema

- No reference keeps a web session 30 to 90 days by default; new-api's 30 days is the longest, and only Coder extends
  a session as it is used.
- Two ship a password and one of them had to refuse it from another machine; the two that ship none take the first
  password on the server or from a first-run page.
- bcrypt at cost 10 is the commonest way to keep the password (four of seven); an HttpOnly cookie with
  `SameSite=Lax` is what the browser holds in five.
- Hypomnema already keeps client tokens as SHA-256 rows behind one middleware, which is Coder's shape for a session.
